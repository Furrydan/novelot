# Basic requirements for Novelot

## Ability to view available novels

- The user should be able to view novels in the form of either a grid or a list.
- The user should be able to filter novels based on tags, allowing them to select a combination, exclude another combinations and create complex chains of AND and OR statements
- The user should be able to view the story thumbnails in both grid and list form. 
- The user should be able to see the name of the story, the most important tags. Metadata such as description, published date, views, followers, favorites etc should be visible in the form of a hovering popup.
- Tags should have a color-scheme based on importance. 
- Tags should be prioritized if the user is searching for them.
- Metadata:
	- Title
	- Author's name
	- Description
	- Tags
	- Likes
	- Follows
